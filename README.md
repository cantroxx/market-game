# 시장에 가면

초등학생이 서울의 전통시장과 마트를 이동하며 예산, 가격 비교, 교통비와 수요·공급을 익히는 React/Vite 학습 게임입니다.

## 로컬 실행과 점검

```bash
npm install
npm run dev
npm run check
```

`npm run check`는 프로덕션 번들을 만들어 진입점과 모듈 연결을 확인하는 최소 스모크 검사입니다.

소스 기준은 `src/`이며 `dist/`는 `npm run build`가 만드는 재생성 가능한 산출물입니다. 실제 수정은 `dist/`가 아니라 `src/`에서 합니다.

## 배포

- 운영 주소: <https://market-game-roan.vercel.app/>
- 배포 방식: GitHub 저장소를 연결한 Vercel 정적 빌드로 추정되며, 다음 배포 전 Vercel의 저장소·브랜치 연결을 확인합니다.
- 기준 저장소: <https://github.com/cantroxx/market-game>

## 데이터와 저장소

- 쉬움 모드 플레이 횟수와 난이도 해금은 브라우저 `localStorage`의 `easy_play_count`에만 저장됩니다.
- 별도 회원·학생 데이터베이스나 서버 저장 기능은 확인되지 않았습니다.
- `node_modules/`, `dist/`, 로컬 설정 파일은 Git에 포함하지 않습니다.

## 외부 자료와 알려진 제한

- 현재 지도는 앱 내부 좌표와 SVG로 표현하며 외부 지도 API를 호출하지 않습니다.
- 시장·가격 데이터는 수업용 게임 값이므로 실제 판매 가격이나 상점 정보로 사용하지 않습니다.
- 별도 라이선스 파일은 아직 없습니다. 새 이미지·음원·데이터를 추가할 때는 출처와 이용 조건을 함께 기록합니다.
- 배포 전 `npm run check`와 쉬움 1회 완주, 어려움 해금, 모바일 화면을 확인합니다.
